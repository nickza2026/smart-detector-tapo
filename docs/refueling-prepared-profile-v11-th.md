# .11 — ชุดเสียงที่จัดเตรียมให้แล้ว ไม่ต้องกรอกฟอร์ม WAV

ชุดนี้ใช้ไฟล์เสียงเดิมที่คุณส่ง: ตัวอย่างประกาศพร้อมเติม/สิ้นสุดเป็นต้นแบบ และอีกสามตัวอย่างเป็นเสียงรบกวนสำหรับตรวจการแยกประเภท จัดช่วงวลี เกณฑ์ และhashให้แล้ว ไม่ต้องเลือกWAV/กรอกเวลา/แก้JSONเอง

## ใช้งาน

1. ปิด.10 แตก **SmartTapo-v11-prepared.zip ทั้งชุด** ลงโฟลเดอร์ใหม่ แล้วเปิดSmartTapo.exeในนั้น อย่าคัดลอกเฉพาะEXE เพราะต้องมีโฟลเดอร์ **prepared-profile** อยู่ข้างกัน
2. ไป **เสียง MEmu / ฟังเติม → ฟังประวัติเติมต่อเนื่อง** กด **ใช้โปรไฟล์จากเสียงที่เตรียมให้** เพียงครั้งเดียว
3. รอข้อความพร้อมใช้ ช่องโปรไฟล์จะเติมเอง ระบบคัดลอกเข้าโฟลเดอร์ข้อมูลและผูกcamera_idกับกล้องที่ตั้งไว้ ไม่บังคับให้คุณแก้ชื่อกล้องในJSON ถ้าใช้กล้อง/kitเดิมซ้ำจะใช้สำเนาเดิม ไม่สร้างWAVซ้ำทุกครั้งที่เปิดโปรแกรม
4. ตรวจMEmuอยู่หน้าLiveของกล้องที่ตั้งไว้ เลือกเสียงขาออกที่MEmuใช้ในแท็บทดสอบเสียง จากนั้นยินยอมรอบนี้และกด **เริ่มฟังต่อเนื่อง** ตามเดิม การเตรียมโปรไฟล์ไม่เปิดเสียง/ADB/ฟังหรือส่งข้อมูลให้เอง

ปุ่ม **ตั้งโปรไฟล์เอง (ขั้นสูง)** มีไว้กรณีต้องเปลี่ยนชุดเสียงในอนาคต ไม่ใช่ขั้นตอนที่คุณต้องทำสำหรับชุดนี้

## ตรวจสอบก่อนส่งและขอบเขต

- แก้ข้อผิดพลาดที่ช่วงเงียบดิจิทัลทำให้การประมาณbackgroundfloorผิดจนต้นแบบเดิมไม่ตรงกับตัวเองเมื่อแทรกในstream เก็บthreshold/anchor/ambiguityguardไว้ ไม่แก้ด้วยการลดเกณฑ์ให้เสียงอะไรก็ผ่าน
- เปรียบเทียบช่วงที่ขยายครอบเสียงหลักจากรูปสัญญาณกับเสียงเดิมทั้งห้า และตรวจgain/เสียงรบกวนที่สร้างเพิ่ม ช่วงในชุดนี้คือพร้อมเติม2.80–9.30s และสิ้นสุด4.85–7.25s เกณฑ์correlation0.80 **เตรียมให้แล้ว ไม่ต้องกรอกซ้ำ** ค่าเหล่านี้ไม่ใช่โอกาสถูก80%หรือผลรับรองความแม่นยำ
- ตรวจด้วยoffline replayของPCMเดิมและเวลาทดสอบ/LiveleaseจำลองในtempSQLiteแยกจากข้อมูลจริง ไม่มีรายการสาธิตปนประวัติผู้ใช้ ต้นฉบับไม่เปลี่ยน
- ทั้งสองเสียงบวกเป็นไฟล์ที่ใช้ทำต้นแบบเอง จึงไม่ใช่held-out/liveaccuracy อีกสามไฟล์ช่วยตรวจเสียงหัวจ่าย/รถที่ให้มา ไม่ครอบคลุมเสียงรบกวนทุกชนิด ไม่มีการรับรองการทำงานหลังออกRDP
- Windowsloopbackยังรวมเสียงแอปอื่น ห้ามเปิดคลิปประกาศ/ไฟล์ต้นแบบจากโปรแกรมอื่นบนoutputเดียวกันขณะฟัง แม้ตรวจหน้าLiveได้ก็ไม่ได้ยืนยันว่าเสียงมาจากTapoเพียงตัวเดียว
- **ยังไม่ผูกรูปก่อนประกาศหรือส่งdashboardอัตโนมัติ** ไม่อนุมานยอดเงิน/จำนวนเหรียญจากเสียง รายละเอียดรอบเติม/retention3วัน/ปุ่มหยุดอยู่ใน[คู่มือ.10](refueling-listener-v10-th.md)

## ความเป็นส่วนตัว/เมื่อเตรียมไม่ได้

ZIPมีสำเนาเสียงจริงที่คุณให้เพื่อใช้งานส่วนตัว ไม่อัปโหลดไปGitHub/บริการถอดเสียงหรือรวมเสียงในsourceที่เผยแพร่ เก็บโฟลเดอร์นี้เป็นข้อมูลส่วนตัว ต้นฉบับและสำเนาต้นแบบเป็นการตั้งค่า ไม่ถูกลบตามประวัติ3วัน

หากZIPขาดไฟล์/hashไม่ตรง/กล้องเปลี่ยน/cacheไม่ปลอดภัย จะไม่ใช้โปรไฟล์เก่าเงียบๆแทนการเตรียมที่ล้มเหลว รอการเตรียมเสร็จก่อนปิดโปรแกรม ไม่ต้องลบประวัติหรือแก้DBเพื่อเปลี่ยนรุ่น
