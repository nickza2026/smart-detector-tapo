# เสียงจบรอบใน V48

V48 แก้การถอดรหัสเสียง AAC และเพิ่มวิธีคำนวณฟีเจอร์เสียงรุ่น 2 โดยไม่ลด threshold ของ Ready/End ไม่ถือว่าไฟล์จบ การหยุดฟัง เสียงเงียบ หรือการเชื่อมต่อขาดเป็นเหตุจบรอบ

## การถอดรหัส

AAC อาจถอดออกมาเป็น float ที่เกินช่วงเต็มสเกลเล็กน้อย ตัวรับเดิมปฏิเสธค่าที่เกินขอบเขตและทิ้งความต่อเนื่อง รุ่นใหม่แปลงที่ขอบเขต decoder ผ่าน PCM16 มาตรฐานก่อนคืน float ที่อยู่ในช่วงที่กำหนด ไม่ขยาย validator ของ stream และไม่แก้ไฟล์เสียงต้นฉบับ

## วิธีคำนวณฟีเจอร์

โปรไฟล์ที่ไม่ระบุ `feature_version` ใช้วิธีเดิมรุ่น 1 ส่วนโปรไฟล์ที่ระบุ `feature_version: 2` ใช้การลบค่าเฉลี่ย log-energy ของย่านความถี่ในแต่ละเฟรม แทนการอ้างอิง percentile ของเสียงทั้งหน้าต่าง เพื่อลดผลจากเสียงแวดล้อมก่อนและหลังคำประกาศ การสร้าง template และการตรวจเสียงใช้วิธีรุ่นเดียวกัน มี version ผูกกับ fingerprint ไม่ตีความโปรไฟล์เดิมเป็นวิธีใหม่อย่างเงียบ ๆ

ไฟล์ Ready/End ที่เตรียมให้ยังเป็นไฟล์อ้างอิงเดิม ไม่เพิ่มไฟล์คลิปที่ผู้ใช้ส่ง ไม่เพิ่ม Whisper หรือโมเดลดาวน์โหลดในโปรแกรม เกณฑ์ raw correlation, temporal correlation และเสียงย่อยอย่างน้อยสองในสามยังคงเดิม การจับเสียงได้ไม่ใช่หลักฐานว่าได้รับเงินจริง

Run All ที่ยังไม่ได้เลือกโปรไฟล์จะเตรียมรุ่น 2 หลังยินยอมเริ่มงาน หากเลือกสำเนาโปรไฟล์เตรียมรุ่นเดิมที่ยืนยันได้จาก receipt ของแอป จะรวมข้อความอัปเกรดไว้ในการยินยอมครั้งเดียว แล้วสร้างสำเนาใหม่โดยไม่แก้ไฟล์เก่า โปรไฟล์ที่เลือกเองไม่ถูกเปลี่ยนอัตโนมัติ สถานะ Run All ระบุวิธีเสียงรุ่นที่ใช้ หากต้องการเปลี่ยนเองให้หยุดเสียงแล้วกดใช้โปรไฟล์จากเสียงที่เตรียมให้

การตั้งเริ่มเสียงพร้อม Windows ที่ผูกกับโปรไฟล์เดิมไม่ได้เปลี่ยนตามอัตโนมัติ ต้องตั้ง binding ใหม่หลังเลือกโปรไฟล์รุ่นใหม่ ไม่แก้ registry หรือยินยอมเริ่มงานแทนผู้ใช้

## การยืนยัน End

ระบบต้องรับเสียงต่อให้มีบริบทเพียงพอสำหรับตรวจประกาศที่อาจทับกัน เวลารอขึ้นกับความยาว template ที่ยาวที่สุด: `2 × ความยาว + 0.4 วินาที` สำหรับชุด Ready 4 วินาทีเป็น 8.4 วินาทีจากจุดเริ่มที่เป็นผู้สมัคร บวกจังหวะประมวลผล ไม่ใช่การเติมเวลาจบให้รอบเอง เวลาของเหตุการณ์เสียงที่บันทึกต่างจากเวลาที่เพิ่งยืนยันสำเร็จได้

คลิปที่หยุดหลังเสียงจบเพียงไม่กี่วินาทีอาจสิ้นสุดก่อนยืนยัน การทดสอบที่ต่อเสียงเงียบสังเคราะห์ 20 วินาทีระบุแยกจากเสียงจริงเสมอ ไม่ใช่หลักฐานว่ากล้องจริงส่งเสียงต่อเนื่องครบ และ EOF จะไม่สร้าง End อัตโนมัติ

การเปลี่ยนโปรไฟล์ไม่เติมเวลาจบย้อนหลัง ไม่ลบรอบขาดช่วง ไม่ปิดรอบที่ยังไม่ยืนยัน และไม่ปลดตัวบล็อก updater แทนผู้ใช้ ต้องตรวจสถานะรอบเติมจริงก่อนการติดตั้ง/เปลี่ยน EXE
