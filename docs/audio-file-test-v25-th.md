# SmartTapo .25 candidate — ทดสอบไฟล์ยาวและวลีห่างกันหลายนาที

## แก้ข้อจำกัดของ .24

ไม่จำกัดความยาวไฟล์ไว้ที่20วินาทีแล้ว WAVถูกอ่านทีละchunk ตัวจับใช้หน้าต่าง20วินาทีที่เลื่อนตามไฟล์ ส่วนสถานะTESTว่าพบวลีเริ่มแล้วจะเก็บต่อข้ามหน้าต่างจนพบวลีสิ้นสุด/จบไฟล์/ยกเลิก **ขนาดหน้าต่างไม่ใช่ระยะเวลาเติมหรืออายุสถานะ** ไม่โหลดเสียงทั้งไฟล์เข้าRAM

## ใช้งาน

1. ปิดSmartTapoตัวเก่า เปิด`.tools/diagnostic-v25/SmartTapo.exe` ไม่ต้องเปิดMEmuหรือให้แอปฟังเสียงจริง
2. **เสียง MEmu / ฟังเติม → ทดสอบไฟล์ออฟไลน์ (TEST) → เลือก WAV → ทดสอบไฟล์**
3. ใช้profileที่เลือกไว้ในหน้าฟังเสียงก่อน หรือprofilestartupกล้องเดียวกัน หรือเตรียมจากเสียงตัวอย่างที่ให้ไว้ ไม่ต้องเขียนJSONเอง ไม่เปลี่ยนprofile/baseline/configที่ใช้อยู่
4. ระหว่างตรวจมีเวลาที่อ่านแล้ว/เวลารวม/เปอร์เซ็นต์ กดยกเลิกได้ ตรวจความครบและhashไฟล์/profileก่อนหลัง หากอ่านไม่ครบ/ไฟล์เปลี่ยน/ยกเลิกไม่เอาผลเก่าหรือผลบางส่วนมาอ้างว่าสำเร็จ
5. ผลภาษาไทยแสดงวลีที่ยอมรับพร้อมoffsetทั้งไฟล์/คะแนนNCC/ส่วนย่อย/เกณฑ์ และช่วงห่างวลีเริ่ม–สิ้นสุดที่จับคู่แบบTEST

## ความหมายผล

- พบเริ่มและสิ้นสุดตามลำดับโดยไม่กำกวม → แสดงเวลาของทั้งสองวลีและช่วงห่างได้ แม้ห่างกันเกิน20วินาทีหรือหลายนาที ไม่เรียกจำนวนนี้ว่าลูกค้าหรือเงิน
- พบเริ่มแต่ไม่มีสิ้นสุด → ข้อมูลไม่ครบ เก็บเป็นpendingเมื่อจบไฟล์ ไม่แต่งวลี/เวลาendและไม่ปิดเอง
- พบสิ้นสุดแต่ไม่มีเริ่ม → แสดงไม่พบเริ่ม ไม่สร้างstartย้อนหลัง
- พบเริ่มหลายครั้งก่อนสิ้นสุด → แสดงกำกวม ไม่เลือกจับเป็นรายการสำเร็จโดยเดา
- จำนวนแถวที่แสดงถูกจำกัดเพื่อคุมRAMได้ แต่ **ไม่หยุดตรวจที่จำนวนแถวนั้น** จำนวนวลี/สถานะTESTยังรับทุกeventตลอดไฟล์และแสดงจำนวนแถวที่ไม่ได้เก็บไว้ ไม่สูญเสียpendingstartเมื่อเลื่อนwindow
- คะแนนNCCไม่ใช่เปอร์เซ็นต์ความมั่นใจ ผลmaximumของwindowไม่ใช่acceptedcandidate และไม่ใช่fullrejectiontraceทุกpeak การวิเคราะห์maxท้ายไฟล์ยาวครอบคลุมwindowท้าย ไม่ใช่คะแนนสูงสุดทั่วทั้งคลิป
- ไม่เติมsilenceท้ายคลิปเพื่อflush ผลEOFเศษchunkยังคงminimumanalysis.25s/ขอบonset/lookahead/overlap/duplicateของตัวจับเดิม ค่าตรวจจับไม่ถูกลดเพื่อให้ผ่าน

## รูปแบบและความปลอดภัย

รองรับregular localWAVPCM16 mono–8channels/sample8–192kHzที่หาร100ลงตัว ตามข้อกำหนดWAV/ตัวอ่าน ไม่รองรับMP4/URL/UNC/ไฟล์ลิงก์ ไม่มีการติดตั้งcodecหรือดาวน์โหลดเพิ่มโดยเงียบ ไม่มีเพดาน20s/64MiBของไฟล์ทั้งก้อนเดิม การhashอ่านเป็นblockและยกเลิกได้ RAMของwindow/ผลลัพธ์ไม่โตตามความยาวไฟล์ แม้การประมวลผลไฟล์ยาวย่อมใช้เวลามากขึ้น

นี่เป็น**TESTไฟล์ที่ผู้ใช้เลือก** ไม่เล่นเสียงออกลำโพง ไม่เปิดTapoPlayback/stream/เปลี่ยนrouteWindows ไม่สร้างproductionLiveLease/รายการเติม/เงินจริง/jobs/outbox/ประวัติลูกค้า ไม่ส่งWebhook/Pushover/API ไม่ปรับproductionmatcherหรือกฎLive

ผลไฟล์ผ่านยืนยันเฉพาะว่าตัวจับตรวจรูปแบบในไฟล์นั้นภายใต้profileนี้ได้ ไม่พิสูจน์ว่าWindows/MEmuส่งเสียงเข้าendpointที่โปรแกรมเลือกได้จริงหรือแก้เคสพลาดของตู้แล้ว ยังไม่มีไฟล์เคสจริงจากผู้ใช้ หลักฐานจำลองต้องระบุว่าเป็นไฟล์สังเคราะห์ ไม่ใช่ลูกค้าจริง
