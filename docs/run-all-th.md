# เริ่มทั้งหมด (Run All)

ปุ่มในแท็บเริ่ม/หยุดสั่งเริ่ม Capture, Worker, เสียง RTSP และ Refueling API จากค่าที่บันทึกไว้ โดยยืนยันการเริ่มฟังและส่ง API หนึ่งครั้ง ไม่เปิดทำงานเองเมื่อเปิดโปรแกรม และไม่เปลี่ยน Windows startup

## ตั้งค่าครั้งแรก

บันทึกแหล่ง RTSP และยืนยันภาพช่องว่างให้พร้อม บันทึก URL/คีย์/สิทธิ์ส่ง Refueling API สำหรับกล้องนี้ ค่าหรือคีย์ที่ยังพิมพ์ค้างไม่ถูกนำไปส่ง หากเปิดแจ้งเตือน Notify API ต้องมี API key ที่บันทึกไว้ด้วย

ใช้โปรไฟล์เสียงที่เลือกไว้ หากยังไม่ได้เลือก ใช้ชุดเสียง prepared-profile ที่จัดให้ผ่านการนำเข้า/ผูกกล้องเดิม ไม่ต้องเปิดหน้าสร้าง JSON ใหม่เอง โปรไฟล์ที่ผู้ใช้เลือกแต่เสียหรือไม่ตรงกล้องไม่ถูกแทนด้วยค่าอื่นอย่างเงียบ ๆ

## เมื่อกดปุ่ม

ตรวจค่าที่บันทึก ภาพช่องว่าง โปรไฟล์ สิทธิ์และปลายทาง API ก่อนเริ่มงาน ยืนยันรวมถึงการผูกคิวที่ยังไม่มีปลายทางของกล้องนี้และเหตุใหม่ไปปลายทางที่บันทึก ไม่ย้ายคิวที่ผูกแล้ว ไม่กู้คิว ไม่ส่งซ้ำ delivered และไม่เปลี่ยน TTL

เปิด API เป็นขั้นสุดท้าย หากเริ่มบางส่วนล้มเหลวทันที จะยกเลิกเฉพาะงานใหม่ของการกดครั้งนี้ ไม่หยุดงานอื่นที่มีอยู่และไม่ลองเริ่มเอง การสั่งสร้าง process สำเร็จยังไม่ยืนยันว่ากล้อง/เสียง/ปลายทางทำงานได้จริง ดูสถานะแต่ละส่วนและ health alerts ต่อไป

ปุ่มหยุดทั้งหมดเดิมใช้หยุดและยกเลิกการเฝ้า/ส่ง กดเริ่มใหม่จึงทำงานต่อ การปิดโปรแกรมหรือสถานะเปลี่ยนระหว่างการยืนยันยกเลิกการเริ่ม ไม่ใช้การเปลี่ยน consent checkbox เพื่อเปิดส่งเอง

## ข้อความตัวบล็อกอัปเดต

หน้าติดตั้งระบุ flag ที่ตรวจพบจริง เช่น listener, webhook, open_round หรือ interrupted_round หากตรวจไม่ได้หรือค่ามีการแก้ไขยังไม่บันทึกจะแจ้งว่าตรวจสถานะไม่ได้ ไม่แต่งชื่อเหตุขึ้นมา

ประวัติรอบเติมขาดช่วงที่ไม่มีเสียงจบอาจยังบล็อกแม้หยุด process แล้ว รุ่นนี้ไม่ได้ลบประวัติ ปิดรอบแทนผู้ใช้ หรือปลด guard ดังกล่าว สาเหตุเฉพาะของ VPS ที่รายงานยังต้องยืนยันจากสถานะของเครื่องนั้น ไม่ใช้ผลจำลองเป็นหลักฐานว่าแก้ VPS แล้ว
