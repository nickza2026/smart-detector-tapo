# SmartTapo .24 candidate — ทดสอบเสียงย้อนหลังจากไฟล์

ผลsource/frozenจำลองไม่ใช่หลักฐานว่าเคสลูกค้าพลาดแก้แล้ว ตรวจreceiptของชุดส่งมอบ ไม่ใช้ผลรุ่นเก่ามาอ้างแทน

## ใช้งาน

1. ปิดSmartTapoตัวเดิม เปิด`.tools/diagnostic-v24/SmartTapo.exe` ไม่จำเป็นต้องเปิดMEmu/SDK/ตัวฟังเสียงเพื่อทดสอบไฟล์
2. ไป**เสียง MEmu / ฟังเติม → ทดสอบไฟล์ออฟไลน์ (TEST)** เลือกWAVแล้วกด**ทดสอบไฟล์** ไม่ได้เล่นเสียงออกลำโพง
3. ใช้profileที่เลือกในหน้าฟังเสียงก่อน ถ้าไม่มีใช้profilestartupของกล้องเดิมหรือเตรียมprofileส่วนตัวจากเสียงตัวอย่างที่มีให้ ไม่ต้องแก้JSONเอง ไม่แก้profileที่กำลังใช้อยู่
4. ผลด้านบนเป็นสรุปภาษาไทย: offset/คะแนนNCC/เกณฑ์/คะแนนส่วนย่อย/เหตุผล ด้านล่างมีmetadataขั้นสูง คะแนนสูงสุดทั้งไฟล์ต้องแยกจากวลีที่ผ่านการจำลองstream ห้ามอ่านจำนวนแถวเป็นจำนวนลูกค้า/เงิน
5. ทดสอบซ้ำไฟล์/profileเดิมได้ กดยกเลิกหรือเปลี่ยนไฟล์/profileผลเก่าจะถูกล้าง ผลงานที่เสร็จช้าไม่กลับมาแสดงเป็นสำเร็จ หากไฟล์ใหม่เสียไม่ใช้ผลไฟล์เก่ามาแทน

รองรับไฟล์ในเครื่องWAVPCM16≤20วินาที/decodedPCM≤16MiB/1–8ช่อง/sample8–192kHzที่หาร100ลงตัวตามstreamเช่น8/16/24/32/44.1/48/96kHz ไม่รองรับMP4/URL/UNC/ไฟล์ลิงก์ ไม่ตัดคลิปยาวเงียบๆ ความยาว20sคือขอบหน้าต่างmatcherเดิม ไม่ใช่เล่นย้อนหลังได้ไม่จำกัด

ถ้าคะแนนผ่านแต่ขึ้นรอlookahead ให้ดูว่าคลิปมีข้อมูลหลังวลียาวพอหรือไม่ ระบบไม่เติมsilenceหรือแต่งendเพื่อflushผล EOFไม่ใช่ประกาศสิ้นสุด เกณฑ์คือส่วนย่อยอย่างน้อย2/3≥.55ร่วมกับคะแนนรูปแบบเต็มของprofile ไม่ลดเกณฑ์ในงานจริง

คงstartup/GUID/healthlogจาก.23 หากผูกWindowsstartupไว้กับEXEรุ่นเก่าและต้องการให้ชี้ตัวใหม่ ให้บันทึกstartupอีกครั้งจากรุ่นใหม่ ไม่ย้าย/ลบEXEที่entryยังอ้างอยู่ ไม่เปิดWebhookข้ามsessionเอง

## เหตุผลและขอบเขต

ผู้ใช้ยืนยันว่าเสียงประกาศออกลำโพงปกติแต่ตรวจไม่ได้ จึงอนุมัติทำเครื่องมือหลังข้อเสนอเริ่มจากไฟล์ย้อนหลัง ไม่ใช่อนุญาตเปิดPlaybackในTapo/สลับหน้ากล้องหรือรับเสียงจริงระหว่างพัฒนา การได้ยินเสียงไม่ยืนยันว่าอุปกรณ์ที่โปรแกรมเลือกส่งPCMเข้าตัวจับหรือวลีผ่านเกณฑ์

เครื่องมือนี้ต้องแยกTESTออกจากLive ใช้matcher/profile/เกณฑ์เดิม แสดงoffsetในไฟล์กับคะแนน/เงื่อนไขที่ตรวจได้ เล่นทดสอบซ้ำด้วยinputเดิมแล้วเทียบผลได้ ไม่ลดthresholdเพื่อให้เขียว ไม่สร้างLiveleaseปลอม ไม่สร้างรอบเติม/jobs/ประวัติเงินจริง ไม่ส่งWebhook/Pushover ไม่เปิดstreamหรือเล่นเสียงออกลำโพงเอง

## สิ่งที่ผลไฟล์ตอบได้

- ไฟล์/profileอ่านได้หรือไม่ รูปแบบ/ความยาว/ขอบเขตที่ประมวลผล
- พบลักษณะตรงวลีที่เวลาoffsetใด คะแนนและเงื่อนไขย่อยที่มีข้อมูลจริงผ่านหรือไม่ผ่านอย่างไร คะแนนNCCไม่ใช่เปอร์เซ็นต์ความมั่นใจหรือหลักฐานเงินเข้า
- ผลบริเวณหัว/ท้ายคลิปต้องมีข้อมูลครบ/lookaheadพอ ไม่แต่งวลีที่ขาด ไม่อ้างว่าEOFคือประกาศสิ้นสุด
- ถ้าไฟล์เดิมตรวจพบแต่เครื่องจริงไม่พบ ให้ตรวจช่องเสียง/Livelease/gap/retryต่อ ผลไฟล์ไม่พิสูจน์เส้นทางWindows→MEmu→อุปกรณ์ที่เลือก
- ถ้าไฟล์เดิมตรวจไม่พบ ต้องดูเหตุที่วัดได้/เวอร์ชันprofile/ความครบวลี ห้ามเดาสาเหตุที่matcherไม่ได้เปิดเผยจากคะแนนเดียว

## ความปลอดภัยและข้อจำกัด

ใช้ไฟล์ที่ผู้ใช้เลือกหนึ่งครั้งและprofileเดิม ไม่อัปโหลดไฟล์ ไม่บันทึกสำเนาPCMเพิ่มเติมโดยไม่จำเป็น ไม่ทดสอบลูกค้าจริง/กล้อง/เสียง/driver/routingระหว่างพัฒนา งานยาวต้องมีขอบเขต ยกเลิกได้ และผลเก่าต้องไม่ถูกแสดงเป็นความสำเร็จของไฟล์ใหม่ที่อ่านไม่ผ่าน

WAVใช้ตัวอ่านเดิมได้ ส่วนMP4ต้องมีdecoderที่รองรับจริง ขณะเริ่มงานไม่พบffmpegจากPATHหรือใต้workspace.tools จึงไม่อ้างว่าแค่เลือกนามสกุลMP4แล้วอ่านได้ ไม่ติดตั้งโปรแกรมglobalหรือดาวน์โหลดcodecโดยเงียบ

ใช้เสียงตัวอย่างที่มีอยู่กับไฟล์สังเคราะห์เพื่อทดสอบซ้ำได้ก่อน ไม่ใช่คลิปเคสล่าสุดที่ผู้ใช้ยังไม่ได้ให้ ยังไม่มีเวลาของเคสหรือรูปแท็บเสียงที่ขอไว้ โหมดทดสอบไฟล์ไม่ใช่การปิดเคสเสียงพลาดย้อนหลังและไม่เปิดงานUIเสียงไม่ผูกเป็นรอบที่พักไว้
