# กรอบติดตามมุมกล้อง — V48

ภาพช่องว่างและพิกัดที่ยืนยันไว้เป็นจุดอ้างอิงคงที่ ไม่ปรับภาพช่องว่างตามภาพใหม่ และไม่เลื่อนพิกัดที่บันทึกแทนผู้ใช้ Worker จัดแนวภาพแต่ละเฟรมเข้าหาภาพอ้างอิง แล้วฉายกรอบกลับไปยังภาพปัจจุบัน

## การติดตาม

ใช้จุดนิ่งรอบช่อง ไม่ใช้เวลา โลโก้ หรือจุดภายในช่องเป็นหลักฐานจัดแนวขั้นสุดท้าย กรณีวัตถุลายถี่ในช่องแย่งจำนวน ORB features จนจับคู่จุดรอบช่องไม่พอ จะลอง proposal เพิ่มหนึ่งครั้งโดยกันพื้นที่กรอบอ้างอิงออกจากการค้นหาจุดในภาพปัจจุบัน ยังคงตรวจและตัดจุดในกรอบที่ฉายไปแล้วออกอีกครั้งก่อนยอมรับ

จำนวน features ยังจำกัด 1,500 ต่อ pass และลองเพิ่มเติมได้เพียงครั้งเดียว ไม่ลดจำนวน inliers ขั้นต่ำ สัดส่วนที่ยอมรับ ความคลาดเคลื่อน ขอบเขตเลื่อน/หมุน ความครอบคลุมรอบช่อง หรือการตรวจพื้นหลังใกล้ช่อง ถ้าตรวจไม่ผ่านยังเป็น UNKNOWN ไม่ใช่ EMPTY ไม่ยืนยันว่าได้รับเงินจริง และไม่ข้ามการเริ่มนับหลักฐานต่อเนื่องใหม่เมื่อมุมเปลี่ยน

## ดูกรอบที่ใช้จริง

ในแท็บเริ่ม/หยุด กด **ดูกรอบที่ติดตามจาก Worker** เป็นหน้าดูแยกจากหน้าตั้งภาพช่องว่าง ไม่เปิดหน้าต่างเองเมื่อเริ่มโปรแกรม ปุ่มนี้ไม่เปิดกล้องเพิ่ม ไม่เริ่ม Capture/Worker/API และไม่ดึงเฟรมออกจากคิวที่ Worker ต้องประมวลผล

ภาพย่อกับกรอบมาจากเฟรมเดียวกับที่ Worker ตรวจ มี session/sequence/generation และเวลาของเฟรมนั้น ส่งใน RAM ไม่เกินหนึ่งครั้งต่อวินาที ภาพย่อไม่เกิน 640×360 และ 128 KiB ตัวควบคุมเก็บเพียงภาพล่าสุด ไม่บันทึกภาพต่อเนื่องลงดิสก์ และไม่ส่งไป Pushover หรือ API

กรอบแดงปรากฏเฉพาะเมื่อเฟรมนั้นผ่านเกณฑ์ตัดสิน ถ้าสถานะไม่แน่นอนแสดงภาพโดยไม่มีกรอบ พร้อมเหตุจัดแนวที่อยู่ในรายการข้อความปลอดภัย ภาพเก่า generation เก่า worker/capture หยุด หรือข้อมูลผิดรูปแบบจะล้างภาพและกรอบ ไม่ค้างกรอบจากเฟรมที่เคยผ่านไว้ ภาพย่อไม่ใช่หลักฐานสำหรับรับเงินจริง

## ขอบเขตหลักฐาน

ภาพ Full-HD สองมุมที่ผู้ใช้ส่งผ่าน geometry ของระบบเดิมอยู่แล้วใน config ประเมินที่ระบุตำแหน่งกรอบโดยประมาณ จึงไม่อ้างว่าได้ทำซ้ำสาเหตุแจ้งจัดแนวบน VPS ส่วนการเทียบภาพหน้าจอขนาดเล็กที่ขยายขึ้นมีความละเอียดและกรอบวาดทับต่างจากเฟรมจริง ไม่ใช้เป็นหลักฐานว่า runtime เสีย

พบและทำซ้ำปัญหา feature budget ถูกวัตถุใน ROI แย่งด้วยภาพสังเคราะห์ มี regression ก่อน/หลังแก้ รวมมุมเดิม มุมขยับ วัตถุ พื้นที่ไร้จุดอ้างอิงและมุมเกินขอบเขต ภาพอ้างอิงไม่เปลี่ยน การทดสอบภาพนิ่ง/GUI จำลองไม่ใช่การรับรองกล้องจริงหรือความแม่นของการตรวจเงินทุกกรณี
